# NEXTHON Documentation

**Welcome to the official NEXTHON documentation.**

NEXTHON is an experimental programming language built with Python, featuring its own lexer, parser and interpreter.

This documentation will help you understand the language, learn its syntax and start writing your own NEXTHON programs.
